Latest firmware for GC Pocket Checking…

What’s new in version 13
  • Rumble no longer turns on by itself In GameCube mode, some games send a “brake” signal to stop the motor quickly. The adapter read it as “on”, so in Super Smash Bros. for Wii U every controller rumbled from the start of a match.
  • Hold a button to change modes Hold the left or right button for about a second and let go when the LEDs show the next mode’s color. A quick press does nothing, so bumping a button can’t change your mode any more.
  • Hold both buttons to save your mode Hold both for about a second to make the current mode the one the adapter starts in. The LEDs blink twice when it is saved.
  • One GameCube mode instead of two GameCube and Slippi are now a single mode. The adapter works out whether it is plugged into a console (purple, 8 ms) or a computer (cyan, 1000 inputs a second) by itself.
  • Switch mode: better rumble and timing Rumble follows what the game asks for much more closely, and inputs are sent in step with the console’s frames.
  • Switch mode on a computer: plug the controller in any time A controller plugged in after the adapter now shows up in Steam. The adapter restarts itself for a moment to make that happen.
  • XInput mode: triggers and sticks rest at zero A trigger that sat a hair above zero, or a centered stick that read slightly off, now reads exactly zero.
  • No more browser pop-up Plugging the adapter in no longer makes Chrome or Edge offer to open this page.
  1. Unplug the adapter from USB.
  2. Hold down both buttons on the adapter and plug it into your computer. Then let go.
  3. Click Install firmware below. The list that opens shows only your adapter, as USB JTAG/serial debug unit: select it and click Connect. If the list is empty, the adapter isn't in update mode, so go back to step 1.
  4. Follow the prompts. When the install is complete, unplug the adapter and plug it back in.

This adapter updates straight from the browser, which only works in Chrome or Edge on a computer. Open this page there to continue.

Using your adapter

Modes

The LED color shows the current mode.

  • SwitchYellow
  • XInputGreen
  • GameCubePurple on a console, cyan on a computer
GameCube mode works out what it is plugged into.

On a console it behaves like Nintendo's own GameCube adapter and sends your inputs every 8 ms. The LEDs stay purple.

On a computer it sends 1000 inputs a second, which is what Slippi and Dolphin want. The LEDs turn cyan a moment after you plug it in.

You don't pick between the two, and there is no separate Slippi mode any more.

XInput mode on the GC Pocket+ shows up as an Xbox 360 wireless receiver.

Each controller you plug in appears on your computer as its own Xbox 360 Wireless Controller, and a port with nothing in it shows as no controller. That is how Steam and Windows tell the four ports apart.

The single-port GC Pocket shows up as one wired Xbox 360 controller.

Changing modes

  • Hold the left or right button for about a second. When the LEDs change to the next mode's color, let go and the adapter switches to it.
  • A quick press does nothing, so bumping a button can't change your mode.
  • Unplug your controllers first: the buttons are locked while a controller is connected.
  • To make the current mode the one the adapter starts in, hold both buttons for about a second. The LEDs blink twice when it is saved.

This describes firmware 13, the current version for both adapters. Older firmware changes mode and saves on a quick press, and has Slippi as its own cyan mode.
